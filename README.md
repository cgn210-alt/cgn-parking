# cgn-parking — CGN 직원 주차 신청·배정

별관 8면과 남경 5면(하루 13면)을 직원 차량에 고르게 나누기 위한 웹앱입니다. 매주 금요일에 다음 주 신청을 받아 이용 횟수가 적은 사람부터 배정합니다.

- 직원 화면: `index.html` (신청 · 현황 · 통계 · 공지)
- 관리자 화면: `admin.html` (직원 · 월별 그룹 · 주간 배정 · 일자별 · 통계 · 공지 · 휴일 · 관리자)

## 운영 규칙

1. 월별 그룹: 직원은 매달 홀수날 또는 짝수날 그룹을 골라 승인 요청합니다. 관리자는 '월별 그룹' 탭에서 양쪽 인원을 보고 한쪽에 몰리지 않게 승인합니다. 요청이 없으면 지난달 그룹이 이어집니다.
2. 주간 신청: 매주 금요일 오후 2시에 다음 주(월~금) 신청이 열리고 2시 30분에 닫힙니다. 토요일·주일·공휴일은 신청을 받지 않습니다. 시간은 서버(인터넷) 시간 기준입니다.
3. 배정안: 2시 30분 마감 직후 자동으로 만들어집니다. 날짜순으로 배정하며 앞 날짜 결과를 횟수에 반영합니다.
   - 별관 8면: 그날 그룹 신청자만 (홀수날 = 홀수 그룹, 짝수날 = 짝수 그룹). 별관이 본관과 가깝고 남경은 멀어서 그룹 날에만 쓰도록 고정. 우선 배정 대상도 자기 그룹 날에만 별관이며 그 안에서 먼저 배정. 그날 그룹 신청자가 8명보다 적으면 남는 별관은 비워 둡니다.
   - 남경 5면: 다른 그룹 신청자와 별관에 들지 못한 신청자
   - 별관 반납·해제로 빈자리가 생기면 그날 그룹 대기자만 승계합니다.
   - 나머지는 대기 순번
   - 순서는 이번 달 이용 횟수가 적은 사람부터, 같으면 날짜와 사람으로 정해지는 추첨
   - 관리자는 오후 4시 전까지 '주간 배정' 탭에서 사람별로 별관/남경/대기/제외를 바꿀 수 있습니다.
4. 발표: 오후 4시에 확정되고 신청자에게 회사 메일로 결과가 갑니다.
5. 당일: 오전 9시까지 '주차 완료'를 누르지 않으면 해제되어 대기자에게 넘어갑니다. 못 오게 되면 '반납'을 누르면 대기 1순위가 받습니다. 별관은 주차 후 퇴근 시까지 출차가 어렵습니다.
6. 미도착 패널티: 배정받고 반납 없이 오전 9시까지 오지 않아 해제되면 다음 주 배정에서 제외됩니다. 사정이 있으면 관리자가 '일자별' 탭에서 면제할 수 있습니다(면제 후 배정안을 다시 만들어야 반영).
7. 이용 횟수는 매월 1일에 초기화됩니다. 반납한 날은 넣지 않고, 미도착은 넣습니다.

공지(신청 일정, 별관 유의사항, 배정 기준)는 관리자 화면 '공지' 탭에서 언제든 고칠 수 있습니다. 처음에는 '기본 공지 불러오기'를 누르면 됩니다.

## 처음 설정

### 1. Firebase
1. Authentication: 이메일/비밀번호 로그인 사용, 승인된 도메인에 `cgn210-alt.github.io` 추가
2. Realtime Database(싱가포르): 규칙 탭에 `database.rules.json` 을 붙여 넣고 게시. 규칙 파일이 바뀌면 다시 게시해야 합니다.
3. 웹 앱 설정값은 `firebase-config.js` 에 들어 있습니다.

### 2. 금요일 자동 실행과 결과 메일 (GitHub Actions)
`.github/workflows/weekly.yml` 이 매주 금요일 13:00, 14:15, 15:30, 17:00(한국 시간)에 `scripts/weekly.js` 를 실행합니다. 신청 일정 만들기 → 2시 30분 배정안 → 4시 발표와 메일 순서이며, 이미 끝난 단계는 건너뜁니다. 저장소 Settings > Secrets and variables > Actions 에 아래 값을 넣어야 동작합니다.

| 이름 | 값 |
|---|---|
| `FIREBASE_DB_SECRET` | Firebase 콘솔 > 프로젝트 설정 > 서비스 계정 > 데이터베이스 비밀번호에 나오는 값 (회사 조직 정책으로 서비스 계정 키를 만들 수 없어 이 방식을 씁니다) |
| `SMTP_HOST`, `SMTP_PORT` | 메일 서버 (예: 구글 계정이면 `smtp.gmail.com`, `465`) |
| `SMTP_USER`, `SMTP_PASS` | 발송 계정과 비밀번호 (구글 계정이면 앱 비밀번호) |
| `MAIL_FROM` | 보내는 사람 표시 (예: `CGN 주차 <계정@gmail.com>`), 비우면 SMTP_USER |

- 메일 설정이 없으면 발표까지만 하고 메일은 건너뜁니다. Actions 탭에서 'Run workflow' 로 언제든 수동 실행할 수 있습니다.
- GitHub 예약 실행은 몇 분 늦을 수 있어 미리 시작해서 정각까지 기다립니다. 자동 실행이 늦어도 오후 4시 이후 직원이나 관리자가 앱을 열면 발표는 처리됩니다(메일은 다음 자동 실행 때 발송).
- 저장소에 60일 동안 변경이 없으면 GitHub 이 예약 실행을 멈춥니다. Actions 탭에서 다시 켜면 됩니다.

### 3. 마스터 관리자와 관리자
마스터 관리자는 주웅현(cgn210@cgnmail.net)이며 모든 권한을 갖고, 다른 관리자를 지정하면서 권한을 골라 줍니다.

| 권한 | 할 수 있는 일 |
|---|---|
| 직원 승인·그룹 | 가입 승인, 이름·차량번호 수정, 삭제, 월별 홀수/짝수 그룹 승인 |
| 우선 배정 지정 | 우선 배정 대상 지정과 해제 |
| 배정·휴일 관리 | 주간 배정안 조정과 발표, 일자별 처리, 미도착 패널티 면제, 휴일 관리 |
| 공지 관리 | 공지 작성, 수정, 고정, 삭제 |

- 마스터 계정은 직원 화면에서 가입하고 메일 인증을 마쳐야 동작합니다.
- 마스터를 바꾸려면 `firebase-config.js` 의 `MASTER_EMAIL`, `MASTER_NAME` 과 `database.rules.json` 의 `cgn210@cgnmail.net` 을 함께 고친 뒤 규칙을 다시 게시합니다.

### 4. 휴일
`parking-core.js` 에 기본 공휴일이 들어 있고, 관리자 화면 '휴일' 탭에서 추가하거나 뺄 수 있습니다(회사 휴무일 포함). 공휴일은 인사혁신처 발표로 확인해 주세요. 이미 만들어진 주는 '주간 배정' 탭의 '휴일 반영해 신청일 다시 계산'으로 반영합니다(신청 시작 전에만 가능).

## 배포
`사이트-올리기.bat` 을 더블클릭하면 1~2분 안에 반영됩니다.

## 알아둘 점
- 승인된 직원은 서로의 이름, 차량번호, 배정 현황, 이용 통계를 볼 수 있습니다(형평성 확인용).
- 반납·대기 처리가 직원 휴대폰에서 이뤄지는 구조라, 승인된 직원은 기술적으로 배정 데이터를 고칠 수 있습니다. 내부용으로는 충분하지만, 문제가 생기면 관리자 화면에서 바로잡을 수 있습니다.
- 우선 배정 대상은 신청한 날마다 별관에 먼저 들어가므로, 지정 인원이 늘수록 다른 직원의 별관 기회가 줄어듭니다.
