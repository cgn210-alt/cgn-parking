# cgn-parking — CGN 직원 주차 신청·배정

별관 8면과 남경 5면을 직원 차량에 공정하게 나누기 위한 웹앱입니다. 도착 순서가 아니라 전날 신청을 받아 자동으로 배정합니다.

- 직원 화면: `index.html`
- 관리자 화면: `admin.html`

## 배정 규칙

1. 신청: 주차하려는 날의 전날 오후 3시까지 신청합니다. 7일 앞까지 미리 신청할 수 있습니다.
2. 배정: 마감이 지나면 앱을 처음 여는 사람의 화면에서 배정이 한 번 확정됩니다.
   - 별관 8면: 우선 배정 대상, 그다음 그날 그룹(홀수날/짝수날) 신청자
   - 남경 5면: 별관에 들어가지 못한 모든 신청자(양쪽 그룹)
   - 나머지 신청자는 대기 순번을 받습니다.
   - 순서는 이번 달 이용 횟수가 적은 사람부터 정합니다. 횟수가 같으면 날짜와 사람으로 정해지는 추첨으로 정하므로, 누가 계산해도 같은 결과가 나옵니다.
3. 오전 9시 해제: 당일 오전 9시까지 '주차 완료'를 누르지 않은 배정은 해제되고, 대기자에게 넘어갑니다. 당일 대기에서 올라온 사람은 해제 대상이 아닙니다.
4. 반납: 못 오거나 일찍 나가면 '반납'을 누릅니다. 대기 1순위에게 자동으로 넘어가며, 별관 자리는 그날 그룹 대기자가 먼저 받습니다.
5. 늦은 등록: 마감 뒤에도 '대기 등록'으로 대기 명단 끝에 들어갈 수 있습니다. 빈자리가 있으면 바로 배정됩니다.
6. 이용 횟수: 매월 1일에 초기화됩니다. 반납한 날은 횟수에 넣지 않고, 미도착으로 해제된 날은 넣습니다.

## 처음 설정 (한 번만)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에서 새 프로젝트를 만듭니다(예: `cgn-parking`).
2. 빌드 > Authentication > 시작하기 > 로그인 방법에서 '이메일/비밀번호'를 사용 설정합니다.
3. 빌드 > Realtime Database > 데이터베이스 만들기 (위치: 싱가포르 asia-southeast1 권장, '잠금 모드로 시작').
4. Realtime Database > 규칙 탭에 `database.rules.json` 내용을 그대로 붙여 넣고 게시합니다.
5. 프로젝트 설정 > 일반 > 내 앱 > 웹 앱 추가 후 나오는 설정값을 `firebase-config.js` 에 붙여 넣습니다.
6. Authentication > 설정 > 승인된 도메인에 `cgn210-alt.github.io` 를 추가합니다.

### 2. 마스터 관리자와 관리자
마스터 관리자는 주웅현(cgn210@cgnmail.net)입니다. 마스터는 모든 권한을 갖고, 다른 관리자를 지정하면서 권한을 골라 줄 수 있습니다.

1. 마스터도 먼저 직원 화면(`index.html`)에서 cgn210@cgnmail.net 으로 가입하고 메일 인증을 마칩니다. 메일 인증 전에는 마스터 권한이 동작하지 않습니다. 주차도 이용한다면 차량 등록 후 관리자 화면에서 본인을 승인합니다.
2. `admin.html` 에 같은 이메일과 비밀번호로 로그인합니다.
3. '관리자' 탭에서 가입한 직원을 고르고 줄 권한을 체크한 뒤 '관리자로 지정'을 누릅니다. 지정된 관리자도 자기 회사 이메일과 비밀번호로 `admin.html` 에 로그인합니다.

마스터가 골라서 줄 수 있는 권한:

| 권한 | 할 수 있는 일 |
|---|---|
| 직원 승인·수정 | 가입 승인과 승인 취소, 홀수/짝수 그룹·이름·차량번호 수정, 삭제 |
| 우선 배정 지정 | 우선 배정 대상 지정과 해제 |
| 일자별 현황 처리 | 주차 완료·해제·반납 처리, 배정 확정·9시 해제 수동 실행 |
| 월별 통계 | 직원별 월 이용 횟수 조회 |

- 관리자 지정·해제와 권한 변경은 마스터만 할 수 있습니다. 권한을 바꾸면 그 관리자의 화면에 바로 반영됩니다.
- 권한이 없는 항목은 화면에서 버튼이 보이지 않고, 데이터베이스 규칙에서도 막힙니다. 다만 '월별 통계'는 화면에서만 가립니다. 배정 기록은 승인된 직원이면 원래 볼 수 있는 정보이기 때문입니다.
- 비밀번호를 잊으면 로그인 화면의 '비밀번호 찾기'로 회사 메일에서 재설정합니다.
- 마스터를 바꾸려면 `firebase-config.js` 의 `MASTER_EMAIL`, `MASTER_NAME` 과 `database.rules.json` 의 `cgn210@cgnmail.net` 을 함께 고친 뒤, 규칙을 다시 게시합니다.

### 3. 직원 등록
1. 직원들에게 `index.html` 주소를 공유합니다.
2. 직원이 회사 이메일로 가입하고 메일 인증한 뒤 이름, 차량번호, 홀수/짝수를 등록합니다.
3. 관리자 화면 '직원' 탭에서 확인하고 승인합니다. 그룹 변경, 우선 배정 지정도 여기서 합니다.

## 배포

GitHub 에 `cgn-parking` 저장소를 만들고 이 폴더를 올린 뒤, Settings > Pages > Source 를 'GitHub Actions' 로 지정합니다. 이후에는 `사이트-올리기.bat` 을 더블클릭하면 1~2분 안에 반영됩니다.

## 알아둘 점

- 별도 서버가 없어서, 배정 확정과 9시 해제는 그 시각 이후 누군가 앱을 열 때 실행됩니다. 직원 누구든 열면 실행되고, 관리자 화면에도 수동 실행 버튼이 있습니다.
- 승인된 직원은 서로의 이름, 차량번호, 배정 현황을 볼 수 있습니다(현장 확인용). 승인되지 않은 사람과 외부인은 볼 수 없습니다.
- 반납·대기 처리가 직원 휴대폰에서 이뤄지는 구조라, 승인된 직원은 기술적으로 그날 배정 데이터를 고칠 수 있습니다. 내부용으로는 충분하지만, 문제가 생기면 관리자 화면에서 바로잡을 수 있습니다.
- 우선 배정 대상은 매일 별관에 먼저 들어가므로, 지정 인원이 늘수록 다른 직원의 별관 기회가 줄어듭니다.
